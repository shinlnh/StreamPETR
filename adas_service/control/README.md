# Controller module for BV ADAS app

**Description**: This module contains source code for Controller module to *create control signal (speed and steering angle)* for the MCU to controll the vehicle base on the path that been planned by the .

# Folder structure
- `/inc`: contains heading file(s) `.hpp` or `.h`
- `/libs`: algorithm's dependency/library
- `/src`: contains `.cpp` or `.c` file(s) for implement algorithm.
- `/simulate`: simulation enviroment for path-planning and controller working together
- `/test`: script/tool for testing purpose
